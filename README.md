# eDoctorat

eDoctorat est une application web de gestion des candidatures au doctorat.
Elle permettra aux candidats de consulter les sujets de thèse et de déposer
leurs dossiers, ainsi qu’aux commissions d’examiner les candidatures.

## État du projet

Nous développons l’application par étapes. Pour le moment, nous avons créé
le modèle de données du back-end avec Java, Spring Boot, JPA et MySQL.
Il couvre notamment les comptes, les candidats, les sujets et les commissions.

Les prochaines étapes sont la création des services et des contrôleurs,
la mise en place des endpoints de l’API, puis le développement du front-end.
